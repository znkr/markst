# Markst - Typst for markup

Markst is a markup language based on [Typst](http://typst.app). It's an
extensible and more versatile alternative to Markdown while keeping the
simplicity. Markst has:

* The simplicity of Markdown for writing prose
* Math notations built-in
* Functions and scripting for more complicated work

Markst is a pure-markup subset of Typst and an HTML renderer. This means, it
doesn't provide any typesetting or layouting functionality and instead defers
that to the browser.

## Example

```typst
= Primes

A natural number $p in NN$ is a prime number if

- $p > 1$ (strictly greater than $1$) and
- it's only positive divisors are $1$ and $p$ itself

#let primes(n) = {
    let primes = (2,)
    let i = 3
    while primes.len() < n {
        let is_prime = true
        for p in primes {
            if calc.rem(i, p) == 0 {
                is_prime = false
                break
            }
        }
        if is_prime {
            primes.push(i)
        }
        i+=1
    }
    primes.map(p => [ $#p$ ]).join(", ")
}

#let n = 10

The first $#n$ prime numbers are: #primes(n)
```

Some notes to explain this example:

* Typst uses `=` instead of `#` for headings, otherwise it's the same `=` is the
  first level of headings, `==` is the second, and so on.
* Inline Math uses `$<math here>$`, Markst renders this to MathML which is
  supported well in most major browsers.
* Lists work similarly to markdown, using `- item` for unnumbered and `+ item`
  for number lists.
* Typst supports executable code. It's started with a `#`. `#let name = ...` is
  a variable definition, `#let func(arg1, arg2) = ...` is a function definition.
* Inside code, content can be embedded using `[ ... ]`, this is used in
  `primes.map(p => [$#p$]).join(", ")` to map the primes (integers) to content
  `[ ... ]` that renders these numbers as math `$#p$`.

For more details, please refer to the excellent [Typst
reference](https://typst.app/docs/reference/).

## Why?

Markdown is too limited and not easy to extend, Typst provides too much, but the
language is really nice and has built-in support for math. Markst is supposed to
fall square in the middle and provide an embeddable, extensible, markup
language.

I am probably going to write more about this in the future.

## Status

Markst is _highly experimental_.

I use it generate my blog at [flo.znkr.io](http://flo.znkr.io) and I already
like it a lot better than Markdown but it's still a long way away from having
a stable API or a full set of features.

## On the use of AI

Markst stated out as a project I wrote from hand, but then became a testbed for
how useful AI is for coding. It turned out to be even more useful than I thought
and large parts of Markst are generated by Claude.
